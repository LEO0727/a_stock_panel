# A Stock Panel

一个轻量的 Windows 桌面 A 股行情工具。默认自选并置顶上证指数、深证成指，支持托盘常驻和多种低打扰显示形态，但不包含伪装、隐藏进程、绕过公司管理等功能。

## 启动

双击：

- `启动软件.vbs`：桌面窗口模式，推荐，不显示命令行黑框
- `start.bat`：桌面窗口模式，启动后命令行会立即返回
- `start_terminal.bat`：终端模式

也可以在项目目录运行：

```powershell
.\start.bat
```

## 显示模式

完整版页面可以直接切换模式、打开设置、添加股票、移除股票、置顶/取消置顶。极简置顶模式不显示设置按钮和模式切换，只显示置顶行情；需要切换时用托盘菜单或右键菜单。

- 完整版：管理自选股、置顶行情、设置显示参数
- 极简置顶：只显示置顶股票/指数，没有可见控件
- 桌面组件：显示全部自选行情，有标题、隐藏和设置入口
- 市场摘要：一条深色状态栏，适合只看市场方向
- 终端模式：运行 `start_terminal.bat`
- 任务栏/托盘：托盘常驻，双击托盘图标打开面板，托盘菜单显示置顶行情

## 系统托盘

托盘依赖已经安装到项目内 `.venv`。如果换电脑后托盘不可用，运行一次：

```powershell
.\install_deps.bat
```

系统托盘默认常驻。双击托盘图标可以打开面板；托盘菜单可以查看置顶行情、切换模式、隐藏窗口或退出。

## 配置文件

配置保存在：

```text
config\watchlist.json
```

常用字段：

- `symbols`：自选代码，默认 `1.000001` 和 `0.399001`
- `mode`：`table`、`mini`、`widget`、`summary`
- `color_mode`：`neutral` 或 `market`
- `opacity`：窗口透明度，范围 `0.45` 到 `1.0`
- `refresh_seconds`：刷新间隔，最低 10 秒
- `topmost`：是否置顶
- `minimize_to_taskbar`：关闭时是否最小化到任务栏
- `enable_tray`：系统托盘保持开启
- `pinned_symbols`：置顶行情；极简模式和托盘菜单只显示这些

## 股票代码格式

可以输入普通代码：

- `600519`
- `000001`
- `399001`

也可以输入东方财富 secid：

- `1.600519`
- `0.000001`
- `0.399001`

其中 `1` 通常表示沪市，`0` 通常表示深市。

## 数据说明

当前版本优先使用东方财富公开行情接口，失败时自动切换到新浪行情。公开接口只适合个人轻量查看，稳定性和授权边界可能变化；正式业务或交易决策建议接入有授权的数据服务。
